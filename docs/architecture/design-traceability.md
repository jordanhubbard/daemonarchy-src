# Source authority and acceptance map

`PROJECT.md` owns the full original-source development requirements. The
[source-unit guide](../user/source-units.md) maps the first concrete parser/header/utility
closure. Each unit's public interface and acceptance contract are versioned with
its Component. The [active queue](../roadmap/active-work.md) retains unfinished qualification.

| Requirement | Authored authority | Evidence still required |
| --- | --- | --- |
| SRC-G1 complete coverage | Initial three unit boundaries and explicit shared-header dependency edges | Complete canonical coverage, shared build/bootstrap ownership, native conditional dependency resolution and current locks |
| SRC-G2 original compilation/tests | Current installed Standard binding, parser/utility acceptance and original case inventories | Admitted SDK/test runtime, real source compilation, full original suites and independent acceptance |
| SRC-G3 per-unit packages | Header, parser and utility package requirements | Actual source/build/runtime pkg products, both BOMs, provenance and observed dependency metadata |
| SRC-G4 incremental execution | Explicit source/header/dependency/options/compiler invalidation cases | Measured clean/unchanged/changed native actions and stale-output refusals |
| SRC-G5 installation/recovery | Relocated VM installation/update/rollback requirements | Disposable VM evidence and exact ISO closure integration |
| SRC-G6 original authority | Reviewed in-place adoption, original-boundaries skills and source-unit guide | Continued source custody through each execution |

The generation-workflow declaration is a schema-level candidate-review contract.
The reviewed Standard binding selects the installed framework but has not
qualified native execution. The independent original authority mode must block
regenerative execution; no
generated candidate can silently become upstream implementation or release
authority. The selected units currently have no execution acceptance receipt.
